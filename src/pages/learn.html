How every program works

  1. 01 Learn Plain-language foundations: what AI does well, where it fails and how to use it safely.
  2. 02 Apply Bring a real task from your own work and practise on it with guidance, not a made-up example.
  3. 03 Build Turn what works into a useful first version: a workflow, a prompt set or a prototype.
  4. 04 Implement Put it to work in your real week, with a clear first use and a way to check the output.
  5. 05 Improve Review how it went, gather feedback and refine it until it holds up on its own.
