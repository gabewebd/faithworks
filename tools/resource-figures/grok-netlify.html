The workflow in this guide

From a conversation to a live landing page

1. Brief

You describe the page: purpose, audience, sections, colours, call to action.

2. Build

Grok writes the HTML and CSS, then refines it with your feedback.

3. Connect

You add the Netlify connector in Grok and authorize it once.

4. Deploy

Grok checks the project, confirms the target, then deploys.

5. Live

You get a .netlify.app address to test, share and refine.

You review at every step

Read the code, approve the deploy target, test the live page.

Setting up a deployment by hand versus a connected AI workflow

By hand

1Create a project folder and write the code
2Set up a Git repository and push it
3Create a Netlify project and link the repository
4Check the build settings and publish folder
5Deploy, then find and copy the live address

Best whenyou want full control, a Git history and a team workflow.

Connected AI workflow

1Give Grok a clear brief
2Review and refine what Grok builds
3Add the Netlify connector once and authorize it
4Ask Grok to check the project and deploy it
5Open the live address Grok returns and test it

Best whenyou want a first version live quickly and will review it carefully.

Both still need testing, a security check and a person who approves what goes live.
